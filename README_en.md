### Circuit Basics

- ✅Voltage divider calculator
- ✅Ohm's Law
- ✅LED series resistor
- ✅555 timer
- ✅Series and parallel resistors (supports customized number of components and multi-level series and parallel subgroups, can be left blank for back calculation)
- ✅Series and parallel capacitors (supports customized number of components and multi-level series and parallel subgroups, can be left blank for back calculation)
- ✅RC time constant
- ✅Parallel shunt (supports customized number of branches)
- ✅Reactance and admittance

### Component identification and conversion

- ✅4/5/6-band resistors (click a resistor component to generate its color bands)

- ✅Inductance unit conversion
- ✅SMD capacitor codes
- ✅SMD resistor codes (3 digits, 4 digits, R mark, EIA-96)
